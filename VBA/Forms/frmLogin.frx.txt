frmLogin.frx — Binary Companion File
=====================================

The .frx file is a BINARY file generated by the VBA IDE when you import or
save a UserForm. It stores binary property data that cannot be stored in text
form within the .frm file.

Contents for frmLogin.frx:
--------------------------
- Form Icon (Icon property):        frmLogin.frx:0000
  This is the small icon displayed in the form's title bar. The actual icon
  data (file offset 0x0000) is stored as a binary .ico resource.

How to generate frmLogin.frx:
------------------------------
Since .frx files are binary and cannot be created manually as text, follow
these steps:

1. Open Excel VBA IDE (Alt+F11).
2. Import frmLogin.frm via File → Import File.
3. The VBA IDE will automatically generate frmLogin.frx in the same folder.
4. Set the form's Icon property to any .ico file (optional).
5. Export the form again to update the .frx.

If you prefer to skip the icon:
1. Open frmLogin.frm in a text editor.
2. Remove or comment out this line:
       Icon = "frmLogin.frx":0000
3. Import the form. VBA will create an empty .frx.

Alternative: Simply ignore the .frx entirely.
- VBA IDE creates a blank .frx automatically when importing a .frm file
  that references binary data it cannot find.
- The form works perfectly without a custom icon.
